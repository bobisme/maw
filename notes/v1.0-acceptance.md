# maw v1.0 acceptance gates (T5.1, bn-l6o7)

This is the checklist that gates the v1.0 tag (bn-z180). Every gate is a
yes/no check against a command or a file. v1.0 ships only when every gate
says MET, or when the user records in this file why a gate was waived.

- **Source:** goal bn-142y "Hard gates", SG5 bn-3ctu, and the child bones
  named in each gate.
- **Owners:** *lead* = the engineering lead (runs the check, fixes, and
  records the evidence). *user* = the project owner (makes the decisions,
  waives gates, approves publication).
- **Status as of 2026-09-28**, trunk `942c68c5` (the last pushed and tagged
  commit is `d414d3de`, v1.0.0-pre.18). A status with no artifact is
  UNKNOWN, not MET.
